CVE-2023-50164 • CRITICAL 9.8 • Dec 7, 2023

Apache Struts RCE: File Upload Vulnerability in Parameters Handling

An attacker can manipulate file upload parameters to enable path traversal and under some circumstances this can be used to upload a malicious file which can lead to Remote Code Execution (RCE). Affected versions of Apache Struts include 2.0.0 through 2.3.37, 2.5.0 through 2.5.32, and 6.0.0 through 6.3.0.

CVE-2021-31805 • HIGH 8.1 • Apr 12, 2022

S2-062: Apache Struts 2.0.0 through 2.5.29 Double Evaluation RCE

Forced double evaluation occurs when Apache Struts 2 tag attributes are evaluated twice based on certain user-controlled inputs. An attacker could provide a malicious expression which, when evaluated the second time, leads to arbitrary code execution on the server.
